Setting it up

  1. In Cloudflare's dashboard, make an API token (My Profile, API Tokens, Create Token, Custom token) with these permissions:
      {% for p in permissions %}
    • {{ p.0 }}, {{ p.1 }}, {{ p.2 }}{% if p.3 %} ({{ p.3 }}){% endif %}
      • {% endfor %}
  2. If Cloudflare asks, turn on R2 (Cloudflare's file storage) once in its dashboard.
  3. For your own address (portal.example.com), its domain's DNS must be on Cloudflare; otherwise the portal gets a free workers.dev address.
  4. Email must be encrypted: SSL/TLS on port 465 or STARTTLS on 587 (Settings, Email). The portal sends sign-in codes itself.
