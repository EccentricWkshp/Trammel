Setting it up

  1. In Cloudflare's dashboard, make an API token with these permissions. Cloudflare recommends an account API token (Manage Account, Account API Tokens, Create Token); a user token (My Profile, API Tokens) works too.
      {% for p in permissions %}
    • {{ p.0 }}, {{ p.1 }}, {{ p.2 }}{% if p.3 %} ({{ p.3 }}){% endif %}
      • {% endfor %}
  2. With an account API token, enter the account ID below. Such a token can't set up the bot check on signing in, so to have one, add a Turnstile widget in the dashboard (Turnstile, Add widget, Managed) for the portal's address and paste its keys below.
  3. Turn on R2 (Cloudflare's file storage) once in its dashboard. Cloudflare asks for a payment method first, even though the free allowance (10 GB stored, 1 million writes and 10 million reads a month) is far more than the portal uses.
  4. For your own address (portal.example.com), its domain's DNS must be on Cloudflare; otherwise the portal gets a free workers.dev address.
  5. Email must be encrypted: SSL/TLS on port 465 or STARTTLS on 587 (Settings, Email). The portal sends sign-in codes itself.
  6. Paste the token below, save, then deploy.
