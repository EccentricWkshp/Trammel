Set up Trammel from your own network

Whoever completes setup becomes the system admin, so it can only be done from the network Trammel runs on, such as a computer in the shop.

To set it up from somewhere else, set SETUP_TOKEN in Trammel's .env file to a long random value, restart Trammel, and enter that value on this page.
