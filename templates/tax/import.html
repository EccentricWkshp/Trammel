Import a tax file

  • SST rate and boundary files — published free each quarter by Streamlined Sales Tax member states. Give the published link or upload the file, as a .zip or the .csv inside; Trammel tells rate files from boundary files by their contents. Import both for the same quarter: the R file has the rates, and the B file maps ZIP and ZIP+4 codes to them, so a rate file alone resolves no address. Washington, for example, names them WAR2026Q4.zip and WAB2026Q4.zip. A new quarter's files replace the state's previous ones entirely; issued invoices keep the rates they used. A state's own downloads in other layouts, such as Washington's address, rate-table and ZIP+4 files, aren't SST files and are refused.
  • Generic CSV — a header row with postal_code, jurisdiction_code, jurisdiction_name, rate, effective_from, effective_to. Rate is a percentage; dates are YYYY-MM-DD. A new CSV replaces the earlier CSV imports unless you tick “Add to the earlier CSV imports”.

Downloading by link is the only time Trammel fetches tax data from the internet; creating an invoice never does. It is refused while outbound traffic is switched off.
